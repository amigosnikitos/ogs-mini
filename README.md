# ogs-mini

Простой клиент для сервера [online-go.com](https://online-go.com) (OGS) под Android.

**Скачать приложение:** вкладка Releases → «OGS Mini latest build» → файл `app-debug.apk`.
Сборка запускается сама после каждого изменения кода и занимает несколько минут.

Подробности (как зарегистрировать приложение на OGS, что умеет, как устроено) — в [OgsMini/README.md](OgsMini/README.md).

## Обновление

Начиная с версии 0.2 приложение подписано постоянным ключом, поэтому новую версию можно ставить поверх старой,
не удаляя приложение. Версию 0.1 нужно один раз удалить перед установкой 0.2: у неё был другой, случайный ключ.
